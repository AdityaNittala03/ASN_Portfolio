# Immersive Dark Portfolio

A modern, interactive portfolio website featuring cutting-edge 3D elements, particle effects, and smooth animations. Built with React and Vite for optimal performance.

## 🌌 Design Philosophy

Pure dark mode experience with rich interactions, 3D elements, and smooth transitions. Each project gets its own dedicated page with immersive galleries.

## 🎨 Features

- **Text Pressure Animation**: Dynamic "Hello" intro with pressure effects
- **3D Photo Model**: Interactive rotating 3D model of profile photo
- **Particle Background**: Continuous particle effects throughout the site
- **Tilted Project Cards**: Interactive project previews with tilt effects
- **Circular Gallery**: Immersive project image galleries
- **Dock Navigation**: macOS-style bottom navigation dock
- **Shape Blur Effects**: Dynamic background blur effects
- **Splash Cursor**: Custom interactive cursor
- **Shiny Text**: Premium text animations
- **Star Border Buttons**: Animated button borders
- **Magnet Lines**: Hover interaction effects
- **Click Sparks**: Visual feedback on interactions

## 🛠 Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: CSS3 with CSS Variables
- **Animations**: Custom CSS & JavaScript
- **3D Graphics**: Three.js
- **Deployment**: Ready for Vercel/Netlify
